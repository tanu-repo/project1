# Project Title

Ezra customer booking page ui automation

## Description

This is a basic framework developed using Playwright

## Getting Started

### Dependencies

node and npm need to be installed


### Installing
git clone https://github.com/tanu-repo/project1.git
cd project1
npm install
install playwright browser -npx playwright install

### Executing program

run all test - npx playwright test
headed mode -npx playwright test --headed

other way to run the tests
npm run test:login
npm run test:booking

  
### Reporting
This basic framework uses html report and it can be opened by running following command after test execution is done
npx playwright show-report
