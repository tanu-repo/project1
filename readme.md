# Project Title

Ezra customer booking page ui automation

## Description

This is a basic framework developed using Playwright

## Getting Started

### Dependencies

node and npm need to be installed


### Installing
git clone https://github.com/tanu-repo/project1.git<br>
cd project1<br>
npm install<br>
install playwright browser -npx playwright install<br>

### Executing program

run all test - npx playwright test<br>
headed mode -npx playwright test --headed<br>

other way to run the tests<br>
npm run test:login<br>
npm run test:booking<br>

  
### Reporting
This basic framework uses html report and it can be opened by running following command after test execution is done
npx playwright show-report
